# Космос Proxy — обязательные требования проекта

## Основа

Проект является публичным fork приложения Hiddify.

Сохраняются:
- стабильная работа ядра;
- работа подписок;
- поддержка Android, iOS, macOS и Windows;
- обязательные лицензии и юридические уведомления.

Пользовательский интерфейс должен быть полностью переработан под бренд «Космос Proxy».

## Приоритет платформ

1. Android — первый рабочий релиз.
2. iOS.
3. macOS.
4. Windows.

Все новые Flutter-компоненты должны оставаться кроссплатформенными.
Нельзя ломать или удалять платформенные папки iOS, macOS и Windows.

## Название

Космос Proxy

## Дизайн

Светлый минималистичный стиль:

- белый и светло-лавандовый фон;
- фиолетовые и синие градиенты;
- небольшие оранжевые акценты;
- мягкие тени;
- крупные скругления;
- космические сферы, планеты и орбиты;
- минимум технических терминов для обычного пользователя.

Приложение не должно визуально восприниматься как Hiddify.

## Брендинг Hiddify

В пользовательском интерфейсе необходимо убрать или заменить:

- название Hiddify;
- логотипы;
- иконки;
- splash screen;
- ссылки на сайт;
- ссылки на поддержку;
- Telegram и социальные ссылки;
- тексты и локализации;
- названия профилей;
- ссылки обновлений;
- deeplink;
- внешние URL;
- remote config, содержащий ссылки Hiddify.

Обязательное авторство и лицензии сохраняются только в:

Настройки → О приложении → Лицензии открытого ПО

Нельзя удалять исходную лицензию или обязательные юридические уведомления.

## Ограничения

- Не удалять поддержку других платформ ради Android.
- Не добавлять release-keystore в Git.
- Не сохранять пароли и секреты в репозитории.
- Не изменять ядро без технической необходимости.
- Не выполнять публикацию и релиз без отдельного разрешения.
- Не выполнять массовые изменения без предварительного аудита.
